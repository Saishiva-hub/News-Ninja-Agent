📰 News Ninja — Agentic AI News Research Assistant

📌 Overview

News Ninja is an Agentic AI-powered news research assistant that helps users search, analyze, and summarize news using Generative AI and intelligent agent workflows.

The project demonstrates how AI agents can use tools and Large Language Models (LLMs) to perform automated news research and generate useful responses.

🎯 Objective

The main objective of News Ninja is to automate the news research process by:

- 🔎 Searching for relevant news
- 📰 Retrieving news information
- 🧠 Analyzing the collected information
- 📝 Summarizing important information
- 🤖 Generating an AI-powered final response

⚙️ Installation

Clone the repository:

git clone https://github.com/YOUR-USERNAME/NewsNinja-Agentic-AI.git

Go to the project directory:

cd NewsNinja-Agentic-AI

Install the required libraries:

pip install -r requirements.txt

🔑 API Key Configuration

If the project requires API keys, configure them using environment variables.

Do not upload API keys or ".env" files to GitHub.

Example:

import os

API_KEY = os.getenv("API_KEY")

▶️ How to Run

1. Clone the repository.
2. Install the required dependencies.
3. Configure the required API keys.
4. Open "NewsNinja21aug.ipynb".
5. Run the notebook cells.
6. Enter a news-related query.
7. News Ninja searches and analyzes the relevant information.
8. View the generated AI response.
